# تصاريح سكنات الجامعة الألمانية للتكنولوجيا في عمان

صفحة عامة لإنشاء تصريح السكن. لا تحتاج الطالبة إلى حساب أو تسجيل دخول، ولا توجد لوحة إدارة أو قاعدة بيانات.

## طريقة الاستخدام

1. تعبئة بيانات الطالبة والأشخاص المصرح لهم.
2. إرفاق صورة بطاقة أو صورة شخصية واضحة لكل شخص مصرح له.
3. اختيار **تنزيل التصريح PDF**، ثم اختيار **Save as PDF / حفظ كملف PDF** من نافذة الطباعة.
4. بعد حفظ الملف، اختيار رابط الفورم وإرفاق ملف PDF.

تتم طباعة التصريح بحجم A3 أفقي. البيانات والصور تبقى في المتصفح ولا تُرسل إلى هذا الموقع.

## النشر

- **GitHub Pages:** سير العمل في `.github/workflows/deploy-pages.yml` ينشر الصفحة عند التحديث إلى فرع `accommodation-permit`. فعّلي Pages في إعدادات المستودع باستخدام GitHub Actions.
- **Render:** ملف `render.yaml` يعرّف موقعاً ثابتاً جديداً ولا يحتاج خادم Node أو متغيرات بيئة أو قاعدة بيانات. إذا كانت لديك خدمة Web قديمة بالاسم السابق، أوقفيها بعد التأكد من أن الموقع الثابت الجديد يعمل، حتى لا تبقى النسخة القديمة متاحة.

أنشئي/حدّثي Blueprint من هذا المستودع لإنشاء الموقع الثابت. لا تحذفي الخدمة القديمة قبل التأكد من أن الموقع الجديد يعمل؛ إعدادات Blueprint لا تحذف تلقائياً متغيرات البيئة الموجودة مسبقاً في لوحة Render.
